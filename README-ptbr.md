# Painel de Acompanhamento de Tempo

Um painel de controle responsivo que exibe dados de acompanhamento de tempo com filtros interativos diários, semanais e mensais.

## Descrição

Este projeto é uma solução para o desafio "Painel de Acompanhamento de Tempo" do Frontend Mentor. O objetivo principal foi construir um painel de uma única página que atualiza seu conteúdo dinamicamente com base na interação do usuário. Este projeto é um excelente exemplo de como usar **JavaScript** para buscar dados (provavelmente de um arquivo JSON), manipular o DOM e criar uma interface de usuário dinâmica que responde à entrada do usuário sem recarregar a página.

## Tecnologias Usadas

* **HTML5:** Para criar a estrutura semântica do painel, incluindo o cartão de perfil e os cartões de atividade.
* **CSS3:** Usado para toda a estilização, incluindo o layout de grade responsivo, cores, tipografia e o design visual dos cartões.
* **JavaScript:** A tecnologia principal que dá vida ao painel. Ela lida com:
    * A busca e o processamento dos dados de acompanhamento de tempo.
    * Ouvir os eventos de clique nos filtros de tempo (Diário, Semanal, Mensal).
    * Atualizar dinamicamente os valores de tempo atual e anterior em todos os cartões de atividade.

## Instalação

Este é um projeto de frontend estático, então não é necessária uma configuração complexa. Para obter uma cópia local, basta seguir estes passos:

1.  Clone o repositório:
    ```bash
    git clone [https://github.com/hangtime319/time-tracking-dashboard.git](https://github.com/hangtime319/time-tracking-dashboard.git)
    ```
2.  Abra o arquivo `index.html` no seu navegador da web preferido para visualizar o projeto.

## Uso

Este projeto serve como uma vitrine de uma interface de painel profissional e funcional. O usuário pode clicar nos filtros no cartão de perfil para mudar instantaneamente o período de tempo para cada atividade, demonstrando uma experiência de usuário fluida e interativa.

## Funcionalidades

* **Exibição de Dados Dinâmicos:** O painel atualiza seus valores em tempo real com base no período de tempo selecionado.
* **Filtros Interativos:** Os usuários podem alternar facilmente entre dados diários, semanais e mensais.
* **UI de Painel Responsiva:** O layout é otimizado para ficar ótimo em todos os tamanhos de tela, de celulares a desktops.
* **Design Limpo e Moderno:** O estilo visual é profissional e intuitivo.
